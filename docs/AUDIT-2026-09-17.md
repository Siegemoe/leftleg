## Fixed — Rust (94afb20 + 2aff61c)

- **CSP was null.** Now: `default-src 'self'; script-src 'self';
  style-src 'self' 'unsafe-inline'; font-src 'self' data:; img-src 'self'
  data: blob: asset: http://asset.localhost https:; connect-src 'self' ipc:
  http://ipc.localhost ws://localhost:1420; object-src 'none'; base-uri
  'self'; form-action 'self'; frame-src 'none'`.
- **Non-async commands ran on the main thread.** pi_start/pi_stop/pi_send/
  append_log/write_agent_extension/read+write_gui_state are now async with
  spawn_blocking; pi_send also stopped swallowing send errors.
- **pi update subprocess hardening:** node-entry spawn (no cmd.exe), bounded
  runtime (600s deadline, tree-kill on timeout), dedicated pipe readers.
- **Log writes:** 5 MiB rotation + 64 KiB line cap, best-effort native log.
- **pi_start scope grant** now happens only after a successful spawn; a
  displaced live process is tree-killed off-thread instead of overwritten.
- **Native path boundaries (2aff61c):** `open_path` command with containment
  (live project dirs ∪ agent dir ∪ app data dir) and an executable-extension
  denylist; tool cards, artifacts, and the logs folder route through it and
  the blanket `opener:allow-open-path '**'` grant is gone. `read_file_base64`
  (path→bytes from the webview) is removed; attachments now use
  `pick_and_read_files` — dialog + read in one native operation, so a
  compromised renderer can only read what the user just picked.
- **pi update single-flight:** native `PI_UPDATE_RUNNING` flag;
  `run_pi_manager` refuses concurrent runs, `pi_start` refuses to spawn
  during an update (npm rewrites the package a live pi runs from).
- **sessions:** `session_display_name` no longer aborts on one bad line;
  `list_sessions` caches parsed sessions keyed by (mtime, size) so sidebar
  refreshes stop re-reading every jsonl.

## Fixed — frontend (b5bf973)

- **Streaming race:** pi flips `isStreaming` before `agent_start` (verified
  in pi 0.85.1 source), so the GUI now treats "prompt accepted but
  agent_start not seen" as streaming (`awaitingAgentStart` map) and sends
  `streamingBehavior: "steer"`. Cleared on agent lifecycle events, pi exit,
  and new session.
- **Management-channel identity (settings companion):** replies now require
  the source to be a real extension command whose sourceInfo path lives in
  `extensions/leftleg-settings/`; ids are `crypto.randomUUID()`; replies
  from wrong origins are ignored (not rejected) so an impostor cannot strand
  in-flight saves; the envelope can no longer be shadowed by spoofed keys.
- **Webview navigation hijack:** document-level capture handler routes
  http(s) anchors to the OS browser and blocks every non-http navigation;
  markdown sanitizer forbids form controls, neutralizes in-page jump
  targets, adds `rel="noopener noreferrer"`.
- **Un-timed status notes** (persisted until the next event) routed through
  `transientNote` across ToolCard, StartScreen, StatusBar, MessageView,
  Artifacts, TitleBar, Composer.
- **Item identity:** all UI items carry required ids; chat is id-keyed
  (was index-keyed → duplicate-key crashes on rebuild); streaming block
  holes are filled; finalizeStreaming skips toolcall blocks.
- **respondToExtDialog** keeps the dialog open on a failed send (retryable)
  instead of discarding it.
- **Composer drafts** are pruned (empty only) on project switch, new
  session, and pi exit; the map no longer grows per visited session.
- **Settings UI:** multi-line textareas no longer eat Enter (mirror +
  commit-on-change); session rename debounce no longer resets mid-typing;
  `companionAvailable()` template reads replaced by a tracked derived.
- **PackageForms:** non-finite numbers are rejected at all four number
  fields (NaN no longer written to settings).
- **Artifacts:** owner-scoped reset — a slow/failed load can no longer show
  another project's files under this project's header.
- **ExtDialog** focus restore + window-level keys; **Sidebar/RightPanel**
  resize switched to pointer capture (mid-drag unmount no longer leaks a
  live handler); **StatusBar** model picker keyboard navigation; TitleBar
  Ctrl+N / Ctrl+B accelerators with modal guards.
- **Companion media extension:** 100 MiB body cap with timeout, 16-image
  and 20 MiB-per-image caps, base64 re-encode check gated to ≤1 MiB inputs,
  realpath containment for reference reads, strict SVG sniff.

## Accepted risks (documented, not fixed)

- **`img-src https:`** keeps remote images renderable in chat/diagrams at
  the cost of remote fetches (tracking pixels). CSP `connect-src` is
  locked to self/ipc, so pixels can only load, not report back data —
  accepted for diagram UX; revisit if a stricter mode is wanted.
- **Companion write TOCTOU** (microsecond window between realpath check and
  write on the media reference path) — needs kernel-level openat semantics
  in Rust to close; realistic risk negligible for a user-scoped agent dir.
- **Devtools in release** — intentional (debugging aid), per project policy.
